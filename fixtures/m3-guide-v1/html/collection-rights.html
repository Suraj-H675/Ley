Choosing a permitted local collection

A local directory tells an importer where bytes can be read. It does not say who owns those bytes, which license applies, or whether a particular use is permitted. Before indexing a collection, identify its author or publisher and read the notice that actually accompanies that material. Keep the notice with the private index evidence when the terms require it. Do not infer permission from a page being publicly reachable, installed on a machine, or technically easy to copy.

Permission has separate parts. Reading a source for personal use, storing extracted text, showing passages to another person, and redistributing a corpus can have different rules. A local retrieval tool should not collapse those questions into one checkbox. The operator chooses the directory and remains responsible for clearing the intended use. A tool can record the source identity and report exactly which files it processed, but that record is evidence of a process, not a legal conclusion.

For a reproducible software demonstration, original fixture text can be dedicated under a clear public license and distributed with an attribution notice. A third-party collection should stay out of the repository unless its terms and every relevant notice permit that distribution. If the source notice is missing or ambiguous, substitute another collection whose rights are clear rather than assuming the missing terms.

Keep the content source and its retrieval address distinct. An operator may map a local file to an HTTP URL for stable provenance while never contacting that address. The mapping is an identity supplied by the operator; it does not prove who published the file or grant rights to use it.
