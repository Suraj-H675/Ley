Field log entry format

The field log records observations with enough context for another volunteer to interpret them.

Required fields

A log entry starts with a session ID such as AR-2026-10-20-N2, a UTC timestamp, the recorder, and the instrument IDs. Each measurement includes its unit and the displayed precision. The recorder marks a missing value as unavailable instead of writing zero, because zero can be a valid reading.

Context and correction

The note field records cloud cover, equipment changes, and unusual noise without replacing measured values with an explanation. If an entry needs correction, the recorder appends a correction line that names the original row and the reason. The measurement-uncertainty page describes how to report a range when the instrument resolution limits precision.

Export

At the end of a session, the recorder checks the export for duplicate timestamps and mixed units. The CSV guide defines the column order, while the data-format page documents how the same row is represented in the archive. This page is the source for the current log procedure in the v1 fixture revision.
