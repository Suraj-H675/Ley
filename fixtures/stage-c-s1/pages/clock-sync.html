Session clock synchronization

The observatory uses one session reference to make timestamps from logs and devices comparable.

Reference display

The operations display shows UTC to the nearest second. At the start of a session, the recorder compares it with the reference time source and writes the observed offset, including its sign. A display that is 1.4 seconds slow is recorded as −1.4 s, not as an unlabeled correction.

Device clocks

A device clock is checked before its first sample and after a reboot. The log keeps the device timestamp and the recorder receipt timestamp when they differ. The difference helps identify buffering or radio delay, but it does not prove which clock failed.

Clock change

If the reference display loses synchronization, the crew marks the affected interval and avoids silently rewriting old rows. The radio handbook defines the message sequence counter; the network map identifies the local time appliance. These references let a reviewer separate message ordering from clock accuracy.
