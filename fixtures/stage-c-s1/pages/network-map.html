Local instrument network map

A text map names the fictional devices on the operations network without exposing real addresses.

Logical links

The recorder uses network label `OPS-NET-A`. The clock appliance is `TIME-01`, the radio console is `RAD-02`, and the archive station is `ARC-01`. These names are scenario identifiers, not live hostnames or addresses. The map stores the link between a device label and its role.

Address records

The fixture map uses documentation-only addresses from reserved examples such as `192.0.2.17` and `2001:db8:4::17`. It shows how an IPv4 and IPv6 value can appear in one record without describing a reachable destination. The link-local guide explains why a zone identifier matters for an IPv6 link-local address.

Change control

A cable move or port change creates a dated map revision. The radio handbook identifies the message endpoint, while the clock page records the time source. A map revision does not by itself prove that a device was reachable during a session; the field log holds that observation.
