Operations power system overview

The operations room uses a mains supply and a monitored battery backup for the recorder and clock display.

What stays powered

The fictional backup circuit supports the recorder, the session display, and the radio console for a limited shutdown interval. It does not power the entire instrument yard. The operations log records the battery test date and the load connected during the test.

Observed fault

If the console reports a transfer to battery, the lead writes the event time and displayed charge. The crew closes the current data file before disconnecting any load. A low charge warning is escalated to maintenance rather than cleared by restarting the display.

Safe work boundary

This overview is not an electrical procedure. The local facility safety plan controls isolation, and only authorized personnel work on the power equipment. The backup page describes a data restore check, not a way to repair the supply.
