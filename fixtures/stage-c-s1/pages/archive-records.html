Archive record handling agreement

A fictional agreement that defines what the station archive retains and how a correction is attached.

Retained record

The archive keeps the original session export, its checksum, and a short record describing who transferred it. A later correction is stored as a new revision with a link to the earlier one. The archive does not replace the first file merely because the new file has more rows or a later timestamp.

Access and copying

A volunteer may make a working copy for analysis, but the copy keeps the source record ID and revision. A derived chart names the input session and the transformation used. A copy without that context is difficult to distinguish from an independent observation.
