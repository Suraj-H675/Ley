CSV export checks

A short procedure for checking a session CSV before adding it to the local archive.

Column and encoding checks

The export uses the field order documented in the data-format page and UTF-8 encoding. A header row appears once. The export check rejects a file if an instrument ID moves into the unit column or if a decoded Unicode label becomes replacement characters such as �.

Quoting

The exporter encloses a field in double quotes when it contains a comma, a quote, or a line break. It doubles an embedded quote. A note such as `mast, east pad` remains one field after import, while a plain identifier such as `WX-04` needs no quotes.

Review before archive

The recorder checks row count, timestamp order, and missing-value markers against the field log. A correction creates a new archive revision with a note; it does not overwrite a file that another session already cited. The archive records page describes that retention rule.
