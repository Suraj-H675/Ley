Night session operating notes

The night session notes cover setup, observation intervals, and the closeout handoff.

Opening the session

The lead checks the site conditions and assigns a recorder before instruments begin sampling. The recorder starts a new session ID and confirms the reference clock. The crew notes which lights remain on, since a lamp can affect the camera even when it does not change an instrument reading.

During a session

A planned pause is written into the log with a start and end time. The crew does not backfill missing readings from memory. If an instrument stops responding, the recorder adds the device ID and message sequence from the radio log so the later review can find the affected interval.

Closeout

At closeout, the lead confirms that each instrument is either left in its documented idle state or listed for maintenance. The recorder checks the CSV export and transfers the session record to the archive. A safety incident follows the incident reporting page even if it does not interrupt the observations.
