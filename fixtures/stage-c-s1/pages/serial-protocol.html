Maintenance serial protocol

The serial protocol defines a bounded frame for local maintenance reads from a device.

Frame layout

A maintenance frame starts with byte `0x7E`, a one-byte device address, a one-byte command, a two-byte payload length, and a checksum. The example status request uses command `0x11` and a zero-length payload. The receiver rejects a frame whose declared length exceeds the local buffer limit.

Response handling

A response repeats the device address and command, then returns a result code and payload. The operator logs the frame sequence and result without copying arbitrary device text into a control command. A timeout can trigger one retry under the maintenance plan, after which the crew records the fault.

Separate channels

This wired protocol is separate from the radio message format. The radio handbook uses a printable station tag and a sequence counter. The identifier registry keeps the device ID stable across both connections, so transport details do not become substitute identities.
