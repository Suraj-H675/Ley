Unicode station labels and export

The station uses UTF-8 labels for informal locations while keeping device IDs ASCII and stable.

Display labels

The eastern window is labeled `北窗` in the volunteer notebook, and the instrument group uses `ΔTₐ` for a temperature difference derived from two probes. These are display labels. The ASCII device ID remains the lookup key because older serial tools accept only a restricted character set.

Normalization

Two strings can look alike while using different Unicode code points. The export preserves the original UTF-8 sequence and records the normalized search label separately when a tool needs one. It does not silently replace a person-entered name with an ASCII approximation.

Review

A CSV round trip checks both byte decoding and visible rendering. A replacement character indicates damaged text, while an accented or CJK label is valid when the original bytes decode correctly. The identifier registry explains which values identify devices and which values are only names shown to volunteers.
