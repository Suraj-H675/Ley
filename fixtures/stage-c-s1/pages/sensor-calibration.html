Sensor calibration record

A calibration record ties a sensor reading to a reference check and a dated adjustment note.

Before a comparison

The calibration record names the device ID, reference instrument, ambient condition, and operator. Both displayed values use explicit units. The operator takes three readings after the sensor settles, then records all three values instead of choosing the one that looks most plausible.

Adjustment history

If the device is adjusted, the record preserves the values from before and after adjustment. A changed offset receives a new calibration event ID, and the field log points to that event when it uses the adjusted instrument. The weather-sensor page gives a worked example for comparing a mast reading with the reference thermometer.

Limits

A calibration check does not establish accuracy outside the tested range. The record states the temperatures or concentrations tested and leaves untested conditions blank. The measurement-uncertainty page explains the difference between instrument resolution and the spread observed during repeat readings.
