Radio control handbook

The fictional radio link carries short control messages between the operations room and field instruments.

Message shape

A control message begins with the station tag ARX, a two-digit device number, and a command code. The example `ARX-17:READ` requests a status sample from unit 17. The response repeats the device number and includes a sequence counter, so the recorder can spot a delayed reply without guessing from arrival order.

Retries

The console waits four seconds for a response and retries once with the same sequence number. A second timeout becomes a log entry, not an invitation to send commands indefinitely. If the unit answers after the retry, the recorder keeps both timestamps and marks the later response as delayed.

Clock and wiring

The radio timestamps come from the operations clock. The clock-sync page explains how that display is compared with the session reference. The serial-protocol page describes the wired maintenance connection, which uses a different frame and must not be confused with this radio message format.
