Incident and interruption report

The report preserves the sequence of an event and separates observed facts from later analysis.

Initial note

The recorder writes the event time, location label, equipment ID, and people notified. The first note uses concrete observations such as “the console restarted at 22:14 UTC” rather than an unverified cause. If a person is injured or a facility alarm sounds, the crew follows the local emergency plan first.

Preserve records

The crew keeps the original field log and any device output needed for review. A correction adds context without replacing the first account. If the event interrupted a measurement, the affected interval stays marked as incomplete instead of being reconstructed from the next sample.

Review

The session lead assigns a follow-up owner and records the review date. The accessibility guide describes how the report remains readable in a linear view. The night-operations page describes the handoff when the event occurs near session close.
