Asteria observation record format

The record format describes field names, units, and identifiers used in exported observations.

Record fields

A data row uses `session_id`, `observed_at`, `instrument_id`, `quantity`, `value`, and `unit`. The timestamp is RFC 3339 in UTC. The `value` field contains a decimal point when needed, and the unit field is never inferred from a column heading in another file.

Missing and uncertain values

A blank value means no reading was recorded. It does not mean zero, and it does not mean that the sensor was offline. The recorder adds a status code such as `sensor_unavailable` when the reason is known. A range belongs in the companion uncertainty fields rather than in a string such as `3.1-3.4`.

Stable identifiers

Identifiers remain stable when a file is copied or a device changes pads. The registry describes the `ARX-17` radio unit and the `WX-04` weather mast. The CSV guide shows how these fields are escaped when a note contains a comma or a Unicode station label.
