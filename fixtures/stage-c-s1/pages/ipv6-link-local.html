IPv6 link-local address notes

A short reference for reading link-local IPv6 values in fictional equipment records.

Scope

An IPv6 link-local address begins with `fe80::/10` and is meaningful only on its local link. A record may need a zone identifier such as `%en0` to say which interface the operator meant. The zone is local notation and can differ between machines.

Example record

The fictional mapping `fe80::a12:4%eth0` is a documentation example, not an address to contact. The operations log stores the interface label beside the address. If the zone is absent, the record may be ambiguous when a host has more than one local network.

Network map

The Asteria network map uses reserved documentation prefixes for examples and lists device names separately from addresses. A copied map must retain the scope note so a reader does not treat an address as globally routed. The map revision date identifies the record version, not the time an endpoint was last reachable.
