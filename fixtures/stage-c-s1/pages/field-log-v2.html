Field log entry format, revision 2

The revised Asteria field log records the clock source beside each session timestamp. A derived reading also names its uncertainty interval and the source rows used to calculate it.

Required fields

An entry starts with a session ID such as AR-2026-10-20-N2, an RFC 3339 UTC timestamp, the recorder, and the instrument IDs. The recorder writes the clock source as `TIME-01` or `manual-check`. A missing value remains unavailable rather than becoming zero.

Derived readings

A derived value names its input row IDs, method, and uncertainty interval. The recorder does not overwrite the raw values. When a method changes, the new calculation gets a distinct record ID so an older report can still be reproduced.

Correction history

The recorder appends a correction that cites the original row and gives the reason. The measurement-uncertainty page explains resolution and repeated readings. The data-format page defines the updated fields used in the export.
